# 墨书 / Active Reader

基于 Readest v0.12.8（`3e4f8210`）的本地阅读 MVP，保留上游 AGPL-3.0 许可。新增功能的代码位于 `apps/readest-app/src/features/`。

## 使用

1. 打开安装的 Active Reader 桌面应用，导入 EPUB，选择快速阅读、分析阅读或主题阅读。开发预览地址为 `http://localhost:3000`，预览书库与桌面书库独立。
2. 快速阅读默认开启字句跟随：周围文字减弱，当前词组保持清晰，小空心光标提供定位。同句停留 5 秒仅出现提醒，点击“留下疑问”后才保存所选的荧光、横线或波浪线标记；页边使用问号角标，标记只贴合实际文字。
3. 阅读工具栏在鼠标触达顶部或底部时显示，也可固定；使用原生左侧目录。单页/双页切换保留原文位置。多书并排时，点击正文或窗格标题选择当前书，布局和阅读工具针对当前窗格。
4. “呼叫小墨”（⌘E / Ctrl+E）围绕选文连续提问，打开后可直接输入；疑问和笔记按钮显示成功状态，再点一次可取消。模型回答按 Markdown 排版。Enter 发送，Shift+Enter 换行，中文输入法确认候选字不会误发送。
5. 主题阅读采用“左侧主题历史＋右侧连续对话”的两栏工作区：历史支持搜索、日期分组和切换，窄窗通过抽屉打开。提出主题或问题后，先在本机检索相关书籍与笔记，再流式回答。可停止、重试和追问；引用编号可查看原文／笔记并跳回书中，随后返回主题对话。“原文与笔记”保留本书笔记与疑问入口。
6. “小墨设置”复用已有 OpenAI-compatible 连接。桌面 Key 使用系统安全存储；网页 Key 只留在当前会话内存。未连接模型时仍能保存笔记、疑问和阅读位置。普通对话与主题历史保存于本机；在“本书对话历史”或“历史主题”中继续旧讨论。停止或失败的回答会保留状态，支持重试或继续生成；保存失败可单独重存。

桌面应用更新后，如果 macOS 请求重新确认钥匙串访问，请在系统窗口中完成授权。等待超过 15 秒会显示说明；可取消当前请求并在确认后重试，无需重新导入书籍。

书籍文件保留在本机。请求 AI 时仅发送问题、限量候选原文、必要邻文、匹配的笔记及对话上下文。人物背景与近况问题默认按需联网，可关闭；无关网页会过滤，必要时回退新闻检索。主题检索采用本地 BM25 文本排序、模型生成的语义查询扩展和候选段落语义筛选，按相关性选段并去重，没有书籍配额。尚未使用本地向量模型，不上传 EPUB 或整个索引。

普通对话与主题阅读共享问题识别和来源规则。“你觉得”等讨论默认不重复注入摘录；“只根据书籍”的范围会随对话保留。流式回答后检查引用是否支持相应说法，检查失败会如实显示。模型输出仍需用户判断，来源检查不是事实正确性的保证。DeepSeek 的复杂讨论启用其思考模式，短解释和查询扩展保持快速模式。

主题工作区已采用用户选定的炭灰柠黄亮色和石墨蓝暗色，左栏底部可选择亮色、暗色或跟随系统，偏好沿用现有本地主题机制。正文区域随窗口扩展，取消固定 820px 上限，保留常规字重、独立标题层级与紧凑引用上标；长回答按论点分节，短追问保持自然段落。输入框位于独立底部区域，不覆盖正文。主题置顶、改名和主题札记编辑器仍在后续计划中。

正式阅读的“阅读背景”提供纯白、淡米白、冷白、雾灰、灰绿、淡青、雾蓝、浅紫、淡粉和夜间共 10 种选择，并保留自定义颜色。纯白现为 `#FFFFFF`，修复了菜单选中纯白而正文 iframe 被替换成暖米色的问题；淡米白使用更浅、低黄调的 `#FAF8F3`。色票、阅读外框与正文共用同一配色，选择保存在本机并在重开后恢复。

阅读器左上角采用小墨 IP。阅读、疑问和查阅姿态分别带有轻微眨眼、点头、飘带和放大镜动作；主题对话只让最新回复的小墨活动，系统减少动态效果及墨水屏模式自动使用静态形象。切换阅读模式、单双页及字句跟随控件使用随背景变化的中性配色。

阅读方式入口保留书名、作者、墨点形象和三个选项，每项一句说明。宽屏会同步放大内容区、封面、墨点、标题和卡片，矮窗口自动收紧，窄窗口改为纵向大按钮；选择期间暂时收起目录，返回正文后恢复。常见桌面窗口无需滚动即可选择，极小窗口及高倍缩放仍可滚动访问内容。

## 开发

需要 Node、pnpm 11.1.1、Rust 和 macOS Command Line Tools。

```sh
git submodule update --init --recursive
pnpm install --frozen-lockfile
cd apps/readest-app
pnpm setup-vendors
pnpm dev-web
```

桌面版本：0.1.10（已安装并验证）。桌面构建：

```sh
pnpm tauri build --config tauri.active-reader.conf.json --bundles app,dmg
```

验证：`pnpm lint`、`pnpm test --run`。当前阅读交互回归入口为 `pnpm exec playwright test e2e/tests/reader-integration.spec.ts`，覆盖真实 EPUB、停留提醒、单双页切换、窄屏、原生并排阅读、选文笔记，以及本地 SSE 协议模拟的流式输出、停止、重试和引用回跳。默认当前产品门禁为 `pnpm test:e2e:web`；已移除的旧工作流按能力映射归档，上游界面另设显式入口，见 `apps/readest-app/docs/testing.md`。

## 当前范围

- 完整流程以 EPUB 为准；PDF 基础阅读沿用上游，PDF 选文 AI、OCR、复杂排版视觉跟随后续做。
- 官方账号、同步、订阅、自动更新、遥测和自动远程字体关闭；在线词典等主动调用的上游功能仍可能联网。
- 旧阅读方法数据继续保留；新模式进度保存在每本书的 `reading-modes.json`，阅读记录继续使用 `reading-method.json`，主题研究保存在 `AppService` 的 `Data` 基目录下的 `thematic-research.json`（macOS 默认是 `Readest/thematic-research.json`）。普通对话保存在 `reading-dialogues.json`。所有笔记与历史对话只在本机持久化，不依赖登录、云数据库或后台上传。写入使用临时文件校验及安全替换，保留上一有效版本；主文件损坏时恢复有效副本并保留损坏原件。书籍定位使用原有 EPUB CFI 和版本标识。网页预览和桌面端的书库各自独立。
- macOS 本地版书籍目录：`~/Library/Application Support/local.activereader.desktop/Readest/Books`；重装应用包不会删除该数据目录。
- AI 协议自动测试使用明确的模拟响应，用于检查流式显示和交互，不用于证明模型回答质量。阅读引擎、原生目录、文字设置、朗读及导入导出沿用 Readest。

## 本地备份与恢复

书库 ZIP 备份使用带版本的清单，包含书籍、原生批注、阅读笔记、疑问、章节思考、普通对话和主题历史；可重建索引不必迁移。恢复旧备份会合并稳定 ID，保留冲突双方，不静默覆盖新记录。每次恢复前会保存本地快照，在备份窗口可撤销最近一次恢复，并导出合并分歧用于核对。快照与导出均留在本机。

桌面数据目录为 `~/Library/Application Support/local.activereader.desktop/Readest`；网页预览使用当前浏览器的 IndexedDB，与桌面数据目录独立。

## 对话质量回归

- 离线回归：`pnpm test --run src/features/reading-modes src/features/active-reading`。
- 真实模型：`MOSHU_LIVE_AI=1 pnpm test --run src/features/reading-modes/conversation.live.test.ts`。覆盖主题、独立判断、理由、反对意见、书籍限定、人物身份和没有书籍的讨论。此测试只在显式启用时读取本机模型配置与钥匙串，并发送限量片段；不输出或持久化 Key。
- 实际联网检索：`MOSHU_LIVE_WEB=1 pnpm test --run src/features/reading-modes/conversation.live.test.ts`，需要本地网页服务已启动。
- 真实回答保存在 `/tmp/moshu-live-evaluation.json` 与 `/tmp/moshu-live-web-evaluation.json`，便于人工审阅；自动断言只检查基本条件，不替代内容审阅。
