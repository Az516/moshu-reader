## 选定的设计参考

最终选择为[炭灰柠黄亮色参考](images/reference-light.png)与[石墨蓝暗色参考](images/reference-dark.png)，保持同一套两栏布局。它们是生成概念图，书名、引文与对话均为设计示例，不是实际模型结果或用户历史。

设计研究参考了 [Bear](https://bear.app/)、[iA Writer](https://ia.net/writer)、[Craft](https://www.craft.do/) 和 [Ulysses 官方主题说明](https://styles.ulysses.app/learn/editor-themes)。借鉴的是中性阅读面、导航与正文的区分，以及局部强调色的使用；具体出处和观察边界见[配色依据](design/color-references.md)。本目录不复制第三方产品截图。

## 归档范围

本目录只保存 Markdown 说明、两张选定概念图和五张测试界面图。不上传用户书籍、笔记、实际问答、模型配置与密钥、原生私人截图、验证日志、数据清单、应用包或本机生成临时文件。旧报告指向这些附件的链接已改为“本机验证资料，未上传”。通用的 `~/Library/Application Support/local.activereader.desktop/Readest` 路径仅用于解释产品的本地存储约定。

测试结果保留原始边界：0.1.10 全量单测出现一次超时后专项通过；18 项浏览器回归首轮 17 项通过，修正旧布局约束后受影响的 4 项通过。没有将首次失败或退出清理挂起改写成一次全绿发布。
