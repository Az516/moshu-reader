# 安装与首次使用

[返回下载页](../../README.md) · [0.1.45 全部下载](https://github.com/Az516/moshu-reader/releases/tag/v0.1.45)

## Mac

适用于 Apple 芯片 Mac（M1 / M2 / M3 / M4 等），需要 macOS 12 或更新版本。在左上角苹果菜单 →「关于本机」可以查看芯片型号。

1. [下载 Mac 安装包](https://github.com/Az516/moshu-reader/releases/download/v0.1.45/Moshu_0.1.45_macOS_arm64.dmg)。
2. 打开 DMG，把「墨书」拖进「应用程序」。
3. 从「应用程序」打开「墨书」。更新已有版本时，先退出墨书，再替换应用。

当前 Mac 包采用本地签名，未做 Apple 公证。首次打开如果被 macOS 拦截，请在「系统设置 → 隐私与安全性」查看墨书对应的提示，再按系统提示选择「仍要打开」。仅在确认安装包来自本仓库后操作。

## Windows

适用于 Windows 10 / 11 的 Intel / AMD 64 位电脑。

1. [下载 Windows 安装包](https://github.com/Az516/moshu-reader/releases/download/v0.1.45/Moshu_0.1.45_Windows_x64_setup.exe)。
2. 双击 EXE，按安装向导完成安装。
3. 从开始菜单打开「墨书」。更新已有版本时，先退出墨书。

当前 Windows 包尚未做代码签名。如果 SmartScreen 显示「Windows 已保护你的电脑」，确认下载来自本仓库后，选择「更多信息 → 仍要运行」。安装器会检查 Microsoft Edge WebView2，缺少时首次安装需要联网下载。

## 开始阅读

打开墨书后导入自己的 EPUB。基础阅读、笔记与进度保存可以离线使用，书籍和阅读记录保存在自己的电脑上。

使用 AI 功能时，在「小墨设置 → 模型连接」填写自己的服务地址、模型 ID 和 API Key，然后保存连接。未配置模型时，仍可阅读和记录笔记。
